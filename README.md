# Digital School ID System 🎓📱

A web-based **Digital School ID System** designed to modernize student identification and school management.  
The system replaces physical ID cards with secure digital profiles and QR codes, enabling fast verification and efficient school operations.

🔗 **Live Demo:** https://bekan.pythonanywhere.com

---

## 🚀 Project Overview

The Digital School ID System allows students to register and receive a unique digital ID containing their personal and academic information. Each ID is linked to a **QR code** that can be scanned by authorized staff to instantly retrieve student records.

The platform is built to improve:
- Student identification
- Library management
- Entry and exit tracking
- Overall administrative efficiency

---

## ✨ Features

### 👨‍🎓 Student Features
- Student registration and authentication
- Secure login and logout
- Personal profile page
- Unique QR code linked to student data

### 👩‍🏫 Teacher / Staff Features
- Scan QR codes to access student profiles
- Manage library book borrowing and returns
- Track school entry and exit activities

### 🔐 System Features
- Authentication system (login & signup)
- QR code generation and scanning
- Role-based access control
- Responsive and mobile-friendly design
